# Arrows of the Realm — 射箭塔防 · 游戏设计文档

> 英文网页游戏。玩家扮演守城将军，站在左侧城堡城墙上，用弓箭迎击从右侧涌来的怪物大军。目标：在城墙被攻破前守住每一波，逐关推进、解锁新箭种与技能、培养将军、挑战无尽模式与排行榜。

---

## 1. 玩家幻想 (Player Fantasy)

你是一方国土的最后一位将军。黄昏之下，敌潮从草原尽头压来。你拉弓、屏息、松弦——每一箭都决定城门还能撑多久。你是高台上的神射手，也是身后的最后一道防线。

核心情绪：**专注、瞄准的掌控感 + 一箭制敌的爽快 + 资源取舍的策略 + 越闯越强的成长欲**。

---

## 2. 核心循环 (Core Loop)

```
瞄准(拖拽) → 松手放箭(弹道+风力) → 命中/击杀怪物 → 金币+连击+经验
   → 守住整波 → 波次奖励 → 进入下一波
   → 通关本关 → 三选一遗物(天赋) + 升级商店
   → 进入下一关(新怪物/新箭种解锁)
   → 城墙耐久归零 → 失败结算(保留成长, 重试)
```

单局时长目标：一关 3~5 波，约 4~6 分钟；一局(通关或失败)约 10 分钟内，适配碎片化与"再来一关"。

---

## 3. 操作 (Controls)

| 输入 | 动作 |
| --- | --- |
| 鼠标拖动 / 触屏拖动 | 瞄准：拖动距离=拉弓力度，方向=发射角度，实时弹道虚线预览 |
| 松开 | 放箭 |
| 1 / 2 / 3 / 4 / 5 / 6 | 切换箭种（图标底部栏，可点按） |
| Q / E 或 点击按钮 | 释放将军技能（箭雨 / 冰霜新星 等） |
| 空格 / P | 暂停 |
| Esc | 返回/关闭面板 |

移动端：屏幕任意处拖动瞄准（不遮挡中央战场），箭种与技能按钮为大触控目标。

## 4. 机制设计 (Mechanics) —— 吸引力与探索闯关的引擎

### 4.1 弹道瞄准 (Trajectory Aiming)
- 从城墙上的将军处，向鼠标方向拖出方向与力度；力度决定初速，角度决定抛物线。
- 松开前显示**虚线轨迹**（受重力 + 实时风力影响），命中点有高亮预测。
- 顶部显示**风向/风力指示**（每波随机变化），让每一箭都是"读风"的技巧博弈。
- 命中判定：箭与怪物碰撞体；**头部=暴击**（约 2× 伤害 + 金色爆字 + 轻微慢动作顿帧），身体=普通，盾牌=格挡。

### 4.2 箭种体系 (Arrow Arsenal) —— 资源取舍
- **普通箭 (Normal)**：无限、免费，基础伤害。
- **火焰箭 (Fire)**：命中点燃，持续灼烧（DoT），可点燃地面油渍/引爆火药桶。
- **冰霜箭 (Ice)**：减速并概率冻结，冻结中的怪受击伤害提升。
- **穿刺箭 (Pierce)**：贯穿直线上的多个敌人。
- **爆炸箭 (Explosive)**：范围伤害，击退，清群。
- **雷霆箭 (Lightning)**：命中后闪电链跳到附近敌人。
- 特殊箭消耗 **法力 (Mana)**，法力随时间回复；普通箭免费。鼓励"普通清小兵 + 法力应对危机"的取舍。
- 箭种随关卡解锁（见 6），并各自可升级（伤害/效率/额外效果）。

### 4.3 将军技能 (General's Abilities) —— 冷却技，逆风翻盘
- **箭雨 (Arrow Storm)**：指定区域落下箭雨，多段伤害。
- **冰霜新星 (Frost Nova)**：冻结全屏（或大范围）敌人，救场。
- **烈焰之墙 (Wall of Flame)**：地面燃起一道火墙，持续灼烧穿过者。
- **援军 (Reinforcements)**：召唤友方弓手短暂齐射。
- 每局可选带 2 个技能上场（开局选择），冷却较长，逼出"什么时候交大招"的决策。

### 4.4 怪物体系 (Monster Roster) —— 每种都有克制解
| 怪物 | 特性 | 克制思路 |
| --- | --- | --- |
| 步兵 Grunt | 基础近战，慢 | 普通箭即可 |
| 疾跑者 Runner | 快、血少、贴近墙 | 冰霜减速 / 精准预判 |
| 蛮兵 Brute | 高血、慢、攻墙伤害高 | 火焰灼烧 / 集中火力 |
| 盾兵 Shieldbearer | 正面格挡箭矢 | 高抛箭打头顶 / 爆炸震盾 / 冰冻结后打背 |
| 爆破手 Sapper | 携带火药，靠近墙自爆，巨量城墙伤害 | **优先击杀**，击杀引爆可炸附近怪 |
| 治疗师 Healer | 为友军回血 | 优先点杀，冰霜打断 |
| 飞行兽 Flyer | 飞行，无视地面火墙，直线俯冲 | 直射命中，雷霆连锁 |
| Boss（每 5 关） | 多阶段、召唤小怪、技能弹幕 | 读招、留大招、破部位 |

### 4.5 连击与评分 (Combo & Scoring)
- 连续击杀积累**连击倍率**（无伤间隔内连杀提升金币/得分倍率，上限 ×3）。
- **完美波次**（本波城墙零损伤）= 额外金币 + 回复部分法力。
- 暴击、一箭多杀、击杀爆破手都会弹出反馈并加分。

### 4.6 遗物三选一 (Perk Draft) —— 每关结束的 roguelike 惊喜
- 通关后从 **3 个随机遗物** 中选 1 个，本局（本次闯关）持续生效：
  - 例：暴击伤害 +50%、每 10 秒自动放一次火箭、击杀有 20% 掉落法力、城墙每波回复 10%、箭雨冷却 -30% …
- 让每次闯关都不同，制造"再来一局凑更强的组合"的重玩动力。

### 4.7 升级树 (Upgrade Tree) —— 永久成长的探索目标
- 击杀与通关获得 **金币** 与 **经验(将军等级)**。
- **将军**：攻击力、拉弓速度、暴击率、暴击伤害、城墙耐久、法力上限/回复、金币加成。
- **箭种**：各箭种独立等级，提升伤害与特效强度。
- 金币在升级商店花费；升级有明确数值，形成长线"刷—强—闯更难关"的驱动。

### 4.7b 兵线与可部署防御 (Lanes & Deployable Defenses) —— 植物大战僵尸式策略
- **3 条地面兵线**：地面怪物随机从 3 条兵线（上/中/下）推进，飞行怪走空中线；玩家需在多线间权衡火力分配。
- **局内金币建造**：击杀/波次奖励的金币可即时用于建造 3 种防御工事（点击底部建造栏 → 点击战场放置）：
  - **尖刺路障 Spike Barricade**（25g）：拦截本兵线怪物、受击并反伤。
  - **弩炮 Ballista**（60g）：自动向本兵线发射弩箭。
  - **冰霜陷阱 Frost Trap**（35g）：减速踏入的怪物。
- 建造金币与永久升级金币共享——是“当下防御”还是“长远成长”，成为每一关的资源取舍。

### 4.8 关卡地图 (Campaign Map) —— 探索闯关的舞台
- 5 大区域，每区若干关 + 关底 Boss：
  1. **翠绿草原 Grasslands**（新手，解锁 火/冰）
  2. **幽暗森林 Dark Forest**（治疗师、疾跑者，解锁 穿刺）
  3. **霜冻峰 Frozen Peaks**（盾兵强化、冰主题，解锁 雷霆）
  4. **熔岩废土 Volcanic Wastes**（爆破手、火主题，解锁 爆炸）
  5. **王城决战 Citadel**（混合精英 + 最终 Boss）
- 区域以 Boss 关为闸门，通关解锁下一区域与对应箭种。

### 4.9 无尽模式 + 排行榜 (Endless + Leaderboard)
- 通关主线后开启 **无尽模式**：波次无限、难度递增，记录存活波数/总分。
- 通过 `game.leaderboard` 提交总分，冲击排行榜，形成"登顶"的长期目标。

---

## 5. 成功 / 失败 / 重置

- **成功**：守住全部波次 → 结算（金币/得分/遗物三选一）→ 升级商店 → 下一关。
- **失败**：城墙耐久归零 → 失败结算（保留本关已获金币的一部分 + 已解锁内容），可重试。
- **重置**：永久成长(升级/解锁/通关进度)通过 `game.storage` 云端保存；失败不丢成长。

## 6. 首个可玩范围 (First Playable Scope, v1)

- 主菜单 + 关卡选择（区域地图）。
- 拖拽瞄准 + 弹道虚线 + 风力。
- 3 种箭（普通 / 火焰 / 冰霜）+ 2 个技能（箭雨 / 冰霜新星）。

- 连击倍率、完美波次奖励、暴击(爆头)。
- 升级商店（将军 + 箭种）。
- 遗物三选一（每关结束）。
- 关卡进度 + 金币 + 升级持久化存档（`game.storage`）。
- 无尽模式 + 排行榜（`game.leaderboard`）。

## 7. 视觉方向 (Visual Direction)

- **风格**：手绘绘本式中世纪奇幻，黄昏金色时刻暖光，剪影清晰，色彩浓郁。
- **实现**：本作生产美术采用 **Phaser Graphics 程序化绘制**（当前环境未连接图像生成模型）：分层背景（天空渐变/太阳/云/远山/森林/草地）、城堡城墙与城门、将军弓手、8 种剪影化怪物，以及箭矢/粒子/技能特效。统一色板与绘本风剪影保证观感一致，并避免透明底/风格漂移问题。
- **色板**（CSS 变量统一）：
  - 墨紫 `#2b1a2e`（文字/描边）、羊皮纸 `#f4e3c1`（面板）、
  - 金 `#f0b429`（强调/金币）、火 `#e4572e`、冰 `#7fd8e8`、
  - 草绿 `#4c9a52`、石 `#5b6470`、夜蓝 `#1b1f3a`。
- **字体**：标题用衬线体（Georgia/serif + 小型大写），正文系统无衬线，营造史诗感。
- **反馈**：命中爆字、屏幕震动、粒子、暴击慢动作、BOSS 击杀特写。
- **HUD**：克制简洁——顶部城墙耐久 + 波次/得分/金币，底部箭种选择 + 技能按钮，中央战场保持干净。

## 9. 技术架构 (Architecture)

- **引擎**：Phaser 3 + TypeScript + Vite（`base: "./"` 便于发布）。
- **规则与状态**：`src/game/state.ts` 持有可存档状态（金币/升级/通关进度/最高分），场景只做视图与输入。
- **数据**：`src/game/data.ts`（怪物/箭种/技能/遗物/关卡/区域静态表），`src/game/constants.ts`（调优常量与色板）。
- **存档/排行榜**：`src/ohmygame/client.js` 的 `game.storage` / `game.leaderboard`。
- **HUD 与菜单**：DOM 覆盖层（`index.html` + CSS），战场用 Phaser Canvas。
